# 프로스트헤이븐 비공식 한국어 개선 패치

Frosthaven의 영문을 기준으로 새로 옮긴 한국어 번역 패치입니다. **공개 검수용 알파**이며 공식 번역·공식 패치가 아닙니다.

## 다운로드

현재 배포 버전은 **0.1.3-alpha**, 지원 게임은 **Windows x64 Steam판 build 26217927**입니다.

**0.1.2 이하 사용자는 업데이트하세요.** 설치 후에도 번역 플러그인이 비활성화되어 게임의 기존 한국어가 표시되던 오류를 수정했습니다. 게임 실행 재검증은 아직 수행하지 않았습니다.

[Releases에서 배포본 확인](https://github.com/wittch/frosthaven-korean-patch/releases)

릴리스의 `GKfont-Frosthaven-0.1.3-alpha.zip`을 받으세요. GitHub가 자동으로 만드는 **Source code ZIP은 설치용 파일이 아닙니다.**

## 설치

1. Frosthaven을 종료합니다.
2. 배포 ZIP을 별도 폴더에 **모두 압축 해제**합니다.
3. `Install.cmd`를 실행합니다. 자동 탐색에 실패하면 `Frosthaven.exe`가 있는 폴더를 입력합니다.
4. 게임을 직접 실행하고 언어를 **한국어/Korean**로 선택합니다.

기존 BepInEx나 다른 로더가 있으면 설치가 중단됩니다. 기존 모드를 먼저 제거하세요. 지원하지 않는 게임 파일에도 설치하지 않습니다. 게임 업데이트 후에는 새 패치의 지원 빌드를 확인하세요.

Python·AI 모델·별도 폰트 설치는 필요하지 않습니다. 설치 도구는 Windows PowerShell을 사용합니다.

## 업데이트와 제거

게임을 종료하고 **이전에 설치한 배포본의 `Uninstall.cmd`**를 실행한 뒤 새 버전의 `Install.cmd`를 실행합니다. 제거 도구는 설치 기록에 있는 패치 파일만 제거하며 게임 원본과 세이브를 수정하지 않습니다. 사용자가 변경한 패치 파일이 있으면 제거를 중단할 수 있습니다.

스팀 파일 무결성 검사만으로 추가된 모드 파일이 전부 제거되지는 않습니다. `Verify.cmd`는 설치 파일의 일치 여부를 검사하며 게임을 실행하지 않습니다.

## 번역 및 검증 범위

- 영문 카탈로그 전체 **14,003개 항목**: 번역 대조 13,951개, 원문 유지 30개, 빈 원문 22개.
- 기존 한국어를 번역 입력으로 사용하지 않았으며, 로컬 AI 초안을 바탕으로 Codex가 영문과 한국어를 전수 대조·교정했습니다.
- 누락·태그·변수·수치·검수 해시·한글 글리프 검사 및 분리된 폴더의 설치·재설치·제거·원본 보존 시험을 통과했습니다.
- **제작 과정에서 게임을 실행하지 않았습니다.** 사람의 전수 감수, 화면 잘림·줄바꿈, 실제 플레이 및 멀티플레이는 미검증입니다.
- 기존 텍스트를 교체하는 방식입니다. 음성이나 이미지 속 글자, 원래 자막이 없는 인트로 영상에 새 자막을 추가하는 기능은 포함하지 않습니다.

## 포함 파일과 권리

배포본에는 한국어 번역, 플러그인, 설치 도구, 필요한 로더와 해당 라이선스·대응 소스를 포함합니다. 게임 실행 파일·게임 자산·전체 영문 카탈로그·AI 모델은 포함하지 않습니다. 외부 구성요소의 라이선스는 배포본의 `licenses`, 대응 소스는 `src`에서 확인할 수 있습니다. 게임과 상표의 권리는 각 권리자에게 있습니다.
