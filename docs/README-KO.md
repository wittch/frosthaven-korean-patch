# GKfont 프로스트헤이븐 한국어 새 번역

영문 원문을 기준으로 새로 만든 비공식 한국어 패치입니다. 기존 한국어 번역은 번역 입력으로 사용하지 않았습니다. 이벤트·시나리오·퀘스트·아이템·라운드·턴처럼 익숙한 게임 용어를 사용합니다.

## 지원 범위

- Windows x64 Steam판 Frosthaven, build 26217927.
- 설치된 I2Languages 텍스트 카탈로그 14,003개 항목이 대상입니다. 빈 항목과 원문 유지 항목은 상태 파일에서 구분합니다.
- 게임의 한국어 선택 항목을 새 번역으로 대체합니다. 한국어 폰트는 게임에 포함된 것을 사용합니다.
- 음성, 이미지에 그려진 글자, 실행 중 별도 생성되거나 외부에서 내려받는 문장은 대상에 포함되지 않습니다.

## 설치

1. 게임을 종료합니다.
2. ZIP을 다운로드한 뒤 **압축을 모두 해제**합니다. ZIP 안에서 바로 실행하지 마세요.
3. `Install.cmd`를 실행합니다. 게임 폴더를 자동으로 찾지 못하면 `Frosthaven.exe`가 있는 폴더를 입력합니다.
4. 나중에 게임을 직접 실행하고 언어 설정에서 **한국어/Korean**를 선택합니다.

기존 BepInEx나 다른 로더가 있으면 설치를 중단합니다. 기존 모드의 제거 도구로 복원한 뒤 설치하세요. 지원하지 않는 게임 업데이트나 손상된 배포본에도 설치를 중단합니다.

Python, AI 모델, .NET Framework 3.5 설치는 필요하지 않습니다. 설치 도구는 Windows PowerShell을 사용합니다. 배포본의 BepInEx는 게임이 번역 플러그인을 불러오기 위한 로더입니다.

## 제거 및 업데이트

게임을 종료하고 `Uninstall.cmd`를 실행합니다. 업데이트도 이전 버전을 제거한 뒤 새 버전을 설치합니다. 제거 도구는 설치 기록에 있는 파일만 지우며 게임 원본과 세이브를 수정하지 않습니다. 사용 중 만들어진 로그·설정과 다른 파일은 남을 수 있습니다.

설치된 패치 파일을 사용자가 바꿨다면 자동 제거를 중단하므로 안내된 파일을 먼저 따로 보관하세요. 스팀의 파일 무결성 검사만으로는 추가된 모드 파일이 모두 제거되지 않습니다.

## 확인과 제보

`Verify.cmd`는 설치된 파일이 배포본과 일치하는지만 검사합니다. 게임을 실행하지 않습니다. 번역의 의미나 화면에서의 배치를 판정하는 기능은 아닙니다.

오역·용어 불일치·잘린 문구를 발견하면 영문 원문, 현재 번역, 화면 위치, 패치 버전, 게임 빌드를 함께 알려주세요. 이야기나 이벤트 제보에는 스포일러를 표시해주세요.

## 검증 상태

전체 14,003개 항목 처리를 완료했습니다. 번역 대상 13,951개는 Codex가 영문과 한국어를 전수 대조·교정했으며, 원문 유지 30개와 빈 원문 22개를 별도로 구분했습니다. 미검수 로컬 모델 초안은 0개입니다. 누락·태그·변수·수치·검수 해시·한글 글리프 검사와 분리된 폴더에서의 설치·재설치·제거·원본 보존 시험을 통과했습니다.

이 버전은 공개 검수용 알파입니다. AI의 전수 대조를 마쳤지만 사람의 전수 감수나 실제 플레이 검증을 마친 버전은 아닙니다. 제작 중 게임을 실행하지 않았으며 화면 표시·줄바꿈·멀티플레이 호환성은 확인하지 않았습니다. 정확한 결과는 `translation-status.json`, 검수 범위는 `REVIEW-KO.md`, 원문 정정과 남은 불일치는 `SOURCE-NOTES-KO.md`를 확인하세요.

번역 텍스트·플러그인·설치 도구를 배포하며 게임 실행 파일과 원본 자산은 포함하지 않습니다. AI 모델과 전체 영문 카탈로그도 배포본에 포함하지 않습니다. 포함된 외부 구성요소의 라이선스는 `licenses`, 대응 소스는 `src`에 있습니다. 게임과 상표의 권리는 각 권리자에게 있습니다.

## 스팀 커뮤니티 배포

완성된 ZIP과 SHA-256 파일을 다운로드 가능한 곳에 올리고, `STEAM-POST-KO.txt`의 다운로드 주소를 실제 주소로 바꿔 Frosthaven 커뮤니티 가이드나 토론에 게시하세요. 게시한 계정이 배포·업데이트·제보 창구를 맡는 방식입니다. 사용자 계정으로 게시하거나 외부에 파일을 업로드하는 작업은 이 패키지 제작에 포함하지 않았습니다.

스팀 상점의 공식 한국어 번역과 구분되도록 **비공식 새 번역 / 공개 검수용 알파**라는 표기를 유지하세요. 다음 배포에서는 버전·지원 빌드·수정 내역을 함께 올리면 됩니다.
