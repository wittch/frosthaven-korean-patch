# 검수 범위

대상 원문은 Steam build 26079164의 resources.assets에 포함된 I2Languages입니다. 14,003개 ID와 영문 약 314,388단어를 추출했습니다. 다른 한국어 번역을 새 번역의 입력으로 사용하지 않았습니다.

로컬 모델로 초안을 만들고 Codex가 실제 영문과 한국어를 읽어 번역 대상 13,951개 ID를 전수 대조·교정했습니다. 부정·조건·대상·선택 여부·수치·턴과 라운드·카드 소실과 버리기·고유명사를 확인했습니다. 검수 기록의 원문 및 한국어 SHA-256을 최종 번역과 다시 대조했습니다. 원문 유지 30개, 빈 원문 22개를 구분했으며 미검수 로컬 모델 초안과 미대조 항목은 모두 0개입니다.

시험용으로 제외한 초안은 배포 입력에 사용하지 않았습니다. 채택한 모델명과 제작 방식은 provenance.json에 기록했습니다. 제작 중 영문 샘플 네 개로 외부 번역 서비스의 사용 가능 여부를 시험했으나 HTTP 429로 거부되어 번역 결과를 받거나 사용하지 않았습니다. 실제 초안 생성은 로컬에서 진행했습니다.

전체 ID·태그·변수·숫자·빈 번역·타 문자권 출력·반복 및 지시문 잔재 검사를 통과했습니다. 개발진 인명과 회사명은 유지했습니다. 게임의 NotoSansKR TMP 폰트를 정적으로 읽어 한글 11,172음절 수록과 최종 번역의 한글 글리프 누락 0개를 확인했습니다.

플러그인은 실제 게임 어셈블리를 참조해 컴파일했습니다. 별도 스텁 시험으로 원문 해시 불일치 시 적용 거부, 한국어만 변경, 다중행·UTF-8 처리와 잘못된 입력 거부를 확인했습니다. 게임 어셈블리를 실행하는 시험은 하지 않았습니다. 분리된 폴더에서 설치·파일 해시·중복 설치 거부·제거·재설치·다른 파일 보존·원본 해시 보존·기존 모드 충돌 거부·손상된 파일의 쓰기 전 거부·경로 이탈 거부 시험을 통과했습니다.

충돌하는 영문 규칙 중 확인 가능한 항목은 설치된 규칙 DLL을 읽기 전용으로 분석해 교정했습니다. 영문 데이터나 규칙 코드는 수정하지 않았습니다. 시나리오 76의 치료 대상 여부와 93의 공격 우선순위 예외는 실행 조건을 확정하지 못해 각 원문의 차이를 유지했습니다. 정정 근거와 미확정 원문 문제는 SOURCE-NOTES-KO.md에 기록했습니다.

이 결과는 AI의 전수 대조이며 사람이 전체를 감수했다는 뜻이 아닙니다. 오역이 없거나 모든 규칙 설명이 정확하다는 보증도 아닙니다.

사용자의 요청에 따라 제작 과정에서 게임을 한 번도 실행하지 않았습니다. 게임 화면·줄바꿈·글꼴의 실제 출력·런타임 로더 동작·실제 플레이·멀티플레이 검증은 수행하지 않았습니다. 이 때문에 공개 검수용 알파 표기를 유지합니다. 원본 게임 파일과 세이브를 직접 수정하지 않는 번역 오버레이 방식입니다.

## 0.1.1 호환성 갱신

현재 지원 빌드는 26217927입니다. 새 빌드의 영문 14,003개 ID를 기존 검수본과 대조해 추가·삭제·영문 변경 0개를 확인했습니다. 기존 영문·한국어 검수 해시는 그대로 유효하며, 새 게임 파일 해시와 어셈블리를 기준으로 빌드했습니다. 원문 정정 기록의 규칙 분석은 최초 빌드 26079164에 대한 기록입니다. 게임 실행 검증은 수행하지 않았습니다.
