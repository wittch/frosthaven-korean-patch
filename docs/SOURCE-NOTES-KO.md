# 원문 정정과 불일치 기록 — 스포일러 포함

영문 카탈로그는 원본 해시 검증을 위해 변경하지 않았습니다. 아래는 한국어에서 반영한 교정과 남겨 둔 원문 문제입니다. 규칙 확인은 설치된 build 26079164의 DLL을 읽기 전용으로 조사했으며 게임을 실행하지 않았습니다.

## 규칙 코드로 확인한 정정

| 항목 | 반영 및 근거 |
| --- | --- |
| 비행 상실 | 장애물에서 가장 가까운 빈칸으로 옮긴 뒤 도착 칸의 함정·위험 지형 효과를 적용합니다. 비행 상실 자체의 자동 함정 피해는 없습니다. `CheckPostStopFlying` 확인. |
| 점프 | 착지에서 함정·위험 지형은 적용되지만 험지 추가 비용과 빙판 효과는 무시합니다. `CAbilityMove.CalculateMoveUsed`, `AbilityEnded` 확인. |
| 시나리오 17 | 마지막 압력판들은 동시에 눌려 있어야 합니다. 마지막 방 공개 후 문과 압력판의 연결을 해제하는 처리 확인. |
| 시나리오 20 | 마지막 기둥은 칼날 회전기 출현의 예외입니다. 파괴 전 남은 기둥 수가 하나이면 다른 수호자를 출현시키는 분기 확인. |
| 시나리오 29 | 인접 기둥과 코어를 합쳐 세 개 이하일 때 피해를 줄 수 있습니다. 면역 조건 `list.Count > 3` 확인. |
| 시나리오 39 | 문 수치는 라운드 종료에 감소합니다. `EndRound`의 `LowerDoorTimers` 확인. |
| 시나리오 40 | 소생한 알곡스는 현재 라운드에 행동하지 않습니다. `MarkWontPlayThisRound` 확인. |
| 시나리오 57 | 조각상 간 거리가 3보다 멀어야 합니다. 거리 3 이하를 거부하는 검사 확인. |
| 시나리오 97 | 진영 변경, 다음 라운드 적용, 프로그램 관리자 우선 공격 및 종료 시 해제 확인. 지배되지 않은 몬스터와의 적대 관계를 명확히 했습니다. 특수 행동의 예외를 일반 설명에 추가하지는 않았습니다. |
| 시나리오 100 | 피해 방지 방식에 따라 기억 덱에서 한 장 또는 두 장을 가져옵니다. `TickAvoidedDamageInternal`의 두 분기 확인. |
| 시나리오 110 | 기둥 활성화는 매 라운드 시작입니다. `StartRound` 처리 확인. |
| 시나리오 124 | 뿌리 성장 피해와 밀려남은 비행하지 않는 캐릭터에 적용됩니다. `FlyingAfterConditions` 검사 확인. |
| 시나리오 136 | 배 자동 이동은 매 라운드 시작입니다. `StartRound`와 라운드당 한 번 처리 확인. |

## 문맥에 따른 정정

- 시나리오 129의 AP를 같은 준비 절차의 PP로 통일했습니다. 점수나 비용 수치는 바꾸지 않았습니다.
- 시나리오 38 안내의 Mar'Oth는 같은 제단의 Mar'ogh를 가리키므로 마로흐로 통일했습니다.
- FS058의 unfeathered는 Unfettered, FH64의 Mooshard는 Moonshard, FH125의 Temporal은 Temportal, FS112의 Wolfe는 Wolfie를 가리키는 오탈자로 판단했습니다.
- FS122의 ancestors는 미래에 살아갈 후손을 뜻하는 문맥으로 옮겼습니다.
- WO15 추론의 ‘둘 다 자백했다’는 문장 관계에 맞춰 ‘둘 다 진실을 말한다’로 풀었습니다. WO61의 깨진 연설 구문은 잊지 않겠다는 뜻을 살렸습니다.
- 퍼즐 6의 technological battle은 기술 설명을 뜻하는 문맥으로 옮겼습니다.
- 이벤트 127.1 좌표의 실제 제어 문자 U+0002를 병행 이벤트 124.1과 대조하고 가운데점으로 바꿨습니다. `3M-1L·7A`로 표시하며 문자·숫자 구성 요소를 보존했습니다. 숫자 검증 규칙은 완화하지 않았습니다.

## 원문 차이를 유지한 항목

- 시나리오 76: 물고기 왕을 치료 대상으로 삼을 수 없다는 설명과, 대상으로 삼을 수 있으나 치료량이 0이라는 가이드가 함께 있습니다. 실행 조건을 확정하지 못해 각 원문을 유지했습니다.
- 시나리오 93: 두 인물이 서로만 공격한다는 설명과, 공격할 수 없으면 다른 유효 대상을 찾는다는 가이드의 차이를 유지했습니다.
- 시나리오 57: 방향별 조각상 설명과 최대 배치 수는 위치가 여러 방향 조건을 만족할 여지가 있어 임의의 추가 수치로 고치지 않았습니다.
- FS017의 압력판 수와 단수 표현, FS051의 분기 내 앞선 대사 참조, FS104의 계절·원소 수, FH32의 수치 없는 반격 아이콘, FH72의 누락된 양자택일 구문은 없는 정보를 보충하지 않았습니다.
- 이벤트 127.1의 노란 증기와 초록 증기 표현은 원문을 따랐습니다. 내부 시네마틱 시험 항목은 사용자용 이야기로 재창작하지 않았습니다.

이 기록은 실제 플레이로 규칙을 검증했다는 뜻이 아닙니다. 화면과 실행 흐름의 확인은 수행하지 않았습니다.
