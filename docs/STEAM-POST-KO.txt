[h1]프로스트헤이븐 비공식 한국어 새 번역 — 공개 검수용 알파[/h1]

기존 번역이 어색해서, 영문을 기준으로 다시 옮긴 한국어 패치를 준비했습니다.
이벤트·시나리오·퀘스트·아이템처럼 게임에서 익숙하게 쓰는 표현을 사용하고, 주요 용어를 통일하는 방향으로 만들었습니다.

[b]버전:[/b] 0.1.3-alpha
[b]지원:[/b] Windows x64 Steam판, build 26217927
[b]대상:[/b] 게임 내 I2Languages 카탈로그 14,003개 항목. 빈 문구·기술 약어·개발진 이름 등은 구분하여 처리했습니다.

[h2]다운로드[/h2]

[h2]설치와 제거[/h2]
1. 게임을 종료하고 ZIP의 압축을 모두 해제합니다.
2. Install.cmd를 실행합니다.
3. 게임을 직접 실행한 뒤 언어를 한국어/Korean로 선택합니다.
제거는 게임을 종료한 뒤 Uninstall.cmd를 실행하면 됩니다.
기존 BepInEx나 다른 로더가 있으면 먼저 기존 모드의 제거 도구로 복원해주세요.

[h2]현재 검증 범위[/h2]
영문 기준 번역 대상 13,951개 ID를 Codex가 전수 대조·교정했습니다. 원문 유지 30개와 빈 원문 22개를 합쳐 전체 14,003개 항목 처리를 마쳤습니다.
누락·태그·변수·수치·한글 글리프·검수 해시 검사와 분리된 폴더에서의 설치·재설치·제거·원본 보존 시험을 통과한 공개 검수용 알파입니다.
사람이 전체를 감수하지 않았으며 게임 화면과 실제 플레이, 멀티플레이는 아직 검증하지 않았습니다.
음성·이미지 속 글자는 번역 대상에 포함되지 않습니다.
공식 번역이나 공식 패치가 아닙니다. 제작 중 게임을 실행하지 않았습니다. 정확한 검사 결과와 남은 원문 규칙 불일치는 ZIP의 translation-status.json, REVIEW-KO.md, SOURCE-NOTES-KO.md에 있습니다.
