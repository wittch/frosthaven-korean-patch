# 설치 도구 소스

이 폴더는 MIT 적용 대상인 설치·제거·검사 도구의 소스입니다. 검토와 수정용이며, 이 폴더만 내려받아 게임에 설치하는 용도가 아닙니다.

실제 사용자는 [릴리스 배포본](https://github.com/wittch/frosthaven-korean-patch/releases)을 받아 압축을 모두 해제한 뒤 배포본의 `Install.cmd`를 실행하세요. 설치에는 배포본의 `manifest.json`과 `payload/`가 함께 필요합니다.

코드 외 자료와 외부 구성요소의 권리는 [별도 안내](../RIGHTS-KO.md)를 따릅니다.
