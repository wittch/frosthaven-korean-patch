# 번역 오버레이 소스

`GKFH.cs`는 0.1.3-alpha 플러그인의 자체 소스이며 MIT로 제공합니다. 배포한 소스에 라이선스 주석만 추가했으며 프로그램 동작은 바꾸지 않았습니다.

빌드에는 Windows .NET Framework C# 컴파일러, 사용자가 보유한 지원 빌드의 게임 참조 어셈블리와 BepInEx/Harmony 참조가 필요합니다. 게임 어셈블리는 이 저장소에 포함하지 않습니다. 번역 데이터와 지원 게임 해시도 배포본의 별도 파일로 제공되므로 소스 코드만 컴파일해서는 완전한 설치본이 되지 않습니다.

일반 사용자는 [릴리스 ZIP](https://github.com/wittch/frosthaven-korean-patch/releases)을 사용하세요. 번역 텍스트와 외부 코드에는 이 소스의 MIT 허가를 적용하지 않습니다. [권리 안내](../RIGHTS-KO.md)를 확인하세요.
